# CodeBuilder IDE

CodeBuilder is a powerful Integrated Development Environment (IDE) built with the MERN stack (MongoDB, Express, React, Node.js). This IDE provides developers with a seamless coding experience, complete with syntax highlighting, live previews, and project management tools.

## Features

- **Real-time code editing**: Edit your code and see the results live.
- **Syntax highlighting**: Enjoy enhanced readability with syntax highlighting for HTML, CSS, and JavaScript.
- **Project management**: Organize your projects easily with folder structures and file management.


## Technologies Used

- **Frontend**: React, HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: MongoDB
